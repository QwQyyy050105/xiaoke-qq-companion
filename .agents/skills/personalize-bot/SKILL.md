# Personalize the bot

先读 README 个性化部分。确认用户要改的是角色表达、模型选择、参与程度还是收信授权；这些属于不同配置入口。

优先使用现有面板与唯一有效人格源。名字、别名、喜恶、语气和关系使用本地人格/配置覆盖层，不覆盖公开默认卡；秘密仅在本机环境或该项目支持的秘密存储中。

按用户给出的风格设计有区分的少量情境对照：叫名、上下文补充、含糊问题和纠正。缺信息先追问关键缺项；示例不当真实经历，表达风格不伪造已联网、读图或执行。

保存后重读并核对下一次实际模型输入采用新卡。检查默认卡字节保持不变；需要重启的配置明确说明。不要为了换名字重写接入层，也不要通过角色文本扩大权限。

移植别的模板时映射字段并保留非敏感结构，重新验模型和传输能力。导出分享前去掉真实关系资料、会话标识、密钥和聊天记录。
