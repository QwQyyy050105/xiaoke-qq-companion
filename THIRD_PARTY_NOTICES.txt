Our implementation adapts chat timing, message formatting, compact context, media and evidence-backed learning ideas to the official QQ Bot API and Codex. No SnowLuma or DeepSeek Harness dependency is installed.

Optional and installed components:
- silk-wasm https://github.com/idranme/silk-wasm (MIT), for QQ SILK encoding.
- undici https://github.com/nodejs/undici (MIT), HTTP/proxy transport.
- https-proxy-agent https://github.com/TooTallNate/proxy-agents (MIT).
- ws https://github.com/websockets/ws (MIT).
- KaTeX https://github.com/KaTeX/KaTeX (MIT), deterministic math layout.
- playwright-core https://github.com/microsoft/playwright (Apache-2.0), optional browser integration. No browser binary is bundled.
Versions are pinned in package-lock.json; dependency licenses remain in installed packages.

Optional speech adapter references Qwen3-TTS (Apache-2.0), https://github.com/QwenLM/Qwen3-TTS.
No model weights, Python runtime, private voice profile, speaker recording or generated personal media are distributed here. Install and review your own providers and licenses before enabling them.
