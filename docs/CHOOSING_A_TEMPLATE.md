# 三个模板如何选择

三个项目各自安装、配置、运行；它们不是同一接入协议的三个皮肤。模型提供商与聊天平台分别配置。

| 项目 | 消息接入 | 部署条件 | 适合谁 |
| --- | --- | --- | --- |
| Xiaoxi / 小汐 | Windows 微信桌面实验适配器 | 已登录微信、受支持版本、可访问的交互桌面及目标会话窗口 | 需要个人微信群陪伴，能接受桌面版本限制的使用者 |
| Xiaoke / 小柯 | 官方 QQ Bot API | QQ 开放平台应用、AppID/AppSecret、平台授予的消息权限；无需个人 QQ 窗口 | 希望按官方平台能力部署的使用者 |
| Fatfish / 蓝色大肥鱼 | OneBot v11 网关；可选 DSH 高级桥接 | 用户独立管理的兼容网关；高级路线还需 DSH | 已有网关或需要 DSH 工具链的开发者 |

小汐当前不提供官方个人微信机器人协议。微信公众号、企业微信和个人微信群聊不能互相替代。未知微信版本、macOS 微信、手机微信均不应推断为已支持。版本不匹配时应停止并报告，不能套用其他版本偏移。

小柯的消息类型、主动发送限制、群聊入口与权限由官方平台授权决定。运行模板不能代替申请平台权限；它不会接管个人 QQ 账号。

大肥鱼与官方 QQ Bot API 是不同路线。模板不捆绑、不安装、不启停第三方 QQ 客户端或网关。OneBot 协议一致不代表所有网关的媒体格式和扩展事件完全一致。

## 架构取舍与角色

- 小汐着重本机桌面陪伴、会话控制、已确认记忆与提醒；原生平台层使用 Python/Win32，需要精确版本兼容。
- 小柯着重官方事件、稳定 OpenID、主人配对、多人任务与发送回执；可选媒体环境独立安装。
- 大肥鱼提供较小的 OneBot + API 默认路线，并保留 DSH 的工具与代理高级路线；后者的部署和调试成本更高。

三者都有独立的默认人格，允许部署者修改。角色风格与平台接入不是绑定关系：喜欢某个角色的说话方式，可以迁移自己的非敏感角色卡，同时重新核对字段映射。速度由模型、网络、上下文和平台发送共同决定，本项目没有宣称某条路线天然更快。

## 模型与功能

| 路线 | 小汐 | 小柯 | 大肥鱼 |
| --- | --- | --- | --- |
| 零网络演示 | Mock | Mock | Mock |
| 常规模型 API | OpenAI-compatible | OpenAI-compatible | OpenAI-compatible 默认后端 |
| 本机代理路线 | Codex，需独立安装和登录 | Codex，需独立安装和登录 | DSH 高级桥接，独立配置 |
| 工具、搜索、语音、图片 | 按安装的适配器和实际能力声明 | 按安装的能力提供者 | 默认 API 仅文本；高级能力取决于 DSH 和网关 |

兼容 API 指支持本项目请求格式的服务，不是任意 HTTP 服务。endpoint、认证变量、模型标识、超时及支持字段见各仓库 README。模型由部署者选择，不应静默切换。普通模型 API 不自动获得联网、读图或语音能力；Mock 成功也不证明真实账号和模型已接通。

## 面板、设备与验收

面板展示各项目实际实现的字段。人格卡负责说话方式、偏好和关系；账号授权、会话范围、插件路径与密钥属于部署配置，不能由聊天内容扩大。

新增会话使用稳定 ID；名称可以重复或更改。共享角色、跨会话记忆和收信权限是不同选项。授权配置提示重启时，应正常重启后重新验收。

当前首先面向 Windows/电脑端。跨系统离线测试只证明核心、配置和模拟协议，不能证明原生聊天平台跨系统可用。支持新设备或版本时，先实现适配器、版本检查和测试，再声明支持。

本地验证应记录系统、Node、提交和命令。真实平台收发、真实模型和媒体需要另外记录，不能由模拟服务器结果替代。
