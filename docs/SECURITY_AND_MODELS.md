# Security and model extension boundaries

这是发布与部署的可核验边界，不是“任何环境零风险”的承诺。公开源码、默认离线运行、启用真实服务是三个不同的检查范围。

## 发布内容

发布候选只包含源代码、虚构夹具、示例配置、许可证和文档。账号配置、.env、聊天、个人媒体、缓存、运行状态和本机凭据不进入版本库。发布检查须针对实际 Git tree 和首次提交历史；不能拿旧版本的测试收据替代。

项目提供 npm run check:release；维护者还应执行独立秘密扫描和人工复核。规则未命中只代表检查覆盖内未发现泄露，不能证明所有未知漏洞不存在。依赖锁定并用 npm audit 检查；新增依赖重新检查许可证与审计结果。

## 默认值与权限

| 项目 | 默认平台范围 | 默认模型 | 高级能力 |
| --- | --- | --- | --- |
| 小汐 | 无账号、无会话；原生与图片缓存关闭 | Mock | 精确 Windows 微信构建、图片段扫描、Codex 与本机插件均需显式配置 |
| 小柯 | 官方 Bot 会话名单为空；主动参与关闭 | Mock | API/Codex、媒体、独立浏览/作图/频道环境分别配置 |
| 大肥鱼 | OneBot 连接关闭、授权名单为空 | 离线 demo 使用独立 Mock；真实 API 尚待配置 | 可信网关、插件与 DSH 高级模式独立启用 |

三者面板绑定 loopback，并验证 Host、Origin 与写入令牌/CSRF。它们抵御普通跨站访问，不隔离同机同用户的恶意进程。不要将面板直接映射公网；远程管理需要另外的认证、TLS 和网络控制。

WX 浏览器模式、QQ、Fish 的本地业务状态不是加密保险箱；.env 也是本机秘密文件。应使用受保护的 OS 账号与数据目录。WX Electron 支持 OS 加密，相关存储失败时不会悄悄退回明文。公开模板不替部署者管理磁盘加密或系统账户权限。

## 模型路线

| 能力 | 小汐 | 小柯 | 大肥鱼 |
| --- | --- | --- | --- |
| 自选提供方与模型 | settings / deployment model | modelProvider | model；高级 DSH provider |
| 内置网络 API | Chat Completions | Chat Completions | 默认 Chat Completions |
| 本机无认证 HTTP | 精确 loopback | 精确 loopback，省略 Authorization | 精确 loopback |
| SSE | 支持，完成后再向微信交付 | 当前 API 非流式 | 默认明确非流式；高级由 DSH 决定 |
| 输出格式 | 文字 | 应用结构化 JSON；服务 JSON mode 或提示词约束后校验 | 默认文字；高级按 DSH 协议 |
| Token 字段 | max_tokens / max_completion_tokens / 省略 | 两字段可选 | 两字段可选 |
| 取消、超时、错误 | 已接线；搜索继承期限；坏包不回显原文 | 已接线；Codex采用配置期限 | 默认 API 已接线；高级桥接独立处理 |
| 原生 Responses / Anthropic / Gemini 协议 | 通过 model 插件扩展 | 通过 chat 插件扩展 | model provider 或 DSH provider 扩展 |

兼容 API 不是任意 HTTP 接口。模型是否稳定输出结构化 JSON、是否能读图、能否使用工具，需分别验证。三者不因失败静默改用另一个模型。普通模型 API 不自动获得联网或设备控制能力。

扩展契约和真实示例见 [扩展契约](EXTENDING.md)。新增提供者可复用现有消息/结果协议，不必修改会话接入层；先用本地 HTTP 假服务测试所选模型名、认证、字段、坏包、超时和取消，再验真实服务。自定义提供者必须遵守取消、输出格式和能力声明。

## 真实服务与可信代码

- 启用云模型或检索后，配置范围内的输入会发往你选择的服务商；服务商属于你需要信任的数据处理方。联网关键词与原始会话上下文不是同一权限。
- 三者插件都是本机可信代码，有宿主进程的文件、环境变量与网络权限。路径/manifest 校验不构成 OS 沙箱。传输插件处在原始事件入口，可能先看到网关输入；宿主保证的是只把授权事件交给自身聊天上下文/模型提供者。
- Codex 路线请求忽略用户配置、关闭已知工具并使用只读策略；所选 CLI 版本/托管配置的最终工具清单仍需独立验收。只读策略不能独自证明没有文件读取能力。旧 CLI 不认识安全参数时应失败，不删参数绕过。
- DSH 高级路线依赖可信 profile、MCP、网关与桥接版本。随附 preset 的工具限制不能自动转移到第三方 profile。默认 API 文本模式不等同于完整 DSH 工具/媒体路线。
- 微信原生适配是非官方实验功能，默认关闭，限定精确版本与 DLL 哈希；平台账号、客户端升级及临时无障碍开关仍有运行风险，不能据本地单测保证所有设备可用。
- 微信模块段扫描另需显式授权，默认关闭；启用后可能短暂经过无关敏感字节，不序列化扫描内容或派生密钥。缓存候选不证明具体发言者或气泡归属。

启用高级执行器前按所用组合验收。没有验收的功能保持 unsupported/未验证，而不是通过人格卡声称可用。

## 验收记录

离线核心、本机 HTTP/WebSocket、面板保存、插件真实调用与模拟原生测试分别记录。真实账号、真实模型和跨系统 CI 分开声明；CI 配置文件不等于 CI 已运行。外部服务、用户安装的软件和后续依赖更新超出一次扫描的保证范围。

发生异常时，保留安全错误码、版本、阶段、取消和不确定回执，不记录上游响应正文或密钥。遇到发送结果不明不盲目补发；撤销会话权限应取消待处理任务并挡住迟到结果。
